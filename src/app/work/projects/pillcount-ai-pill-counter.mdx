## Overview

Developed PillCount, a personal health tech prototype that uses AI to automatically count pills from photos. Built using Flutter and the YOLOv11 computer vision model, this project demonstrates practical application of AI in healthcare workflows.

## The Problem

Pharmacists spend significant time on repetitive manual tasks:
- Counting pills by hand for prescription fills
- Risk of human error in manual counting
- Shrinkage loss from inaccurate inventory management
- Time taken away from patient care activities

## The Solution

Created a mobile application that leverages computer vision for automated pill counting:

- **AI-Powered Recognition**: YOLOv11 model trained for pill detection and counting
- **Mobile-First Design**: Flutter app for on-the-go use in pharmacy settings
- **Real-Time Processing**: Instant pill counting from camera capture
- **User-Friendly Interface**: Simple workflow designed for pharmacist and technician use

## My Role

As the sole product manager and developer, I:
- Conducted design thinking workshops to map pharmacist and technician user journeys
- Performed informal usability tests with peer pharmacists
- Applied agile ideation and iterative prototyping
- Developed the full mobile application with AI integration
- Validated core functionality and ergonomic considerations

## Key Features

- **Camera-Based Detection**: Point and shoot pill counting
- **Multiple Pill Types**: Trained model to recognize various pill shapes and sizes
- **Batch Counting**: Process multiple pills in a single image
- **Results Export**: Save and share counting results
- **Offline Capability**: Core functionality works without internet connection

## Technology Stack

- **Flutter**: Cross-platform mobile development
- **YOLOv11**: State-of-the-art object detection model
- **Python**: Backend processing and model training
- **Computer Vision**: OpenCV for image processing
- **Rapid Prototyping**: Fast iteration based on user feedback

## User Research Approach

Applied human-centered design principles:

- **Journey Mapping**: Documented end-to-end pharmacist workflows
- **Pain Point Analysis**: Identified specific moments of friction
- **User Interviews**: Gathered qualitative feedback from pharmacy peers
- **Usability Testing**: Iterated based on real user interactions
- **Ergonomic Considerations**: Designed for pharmacy counter workflows

## Performance Results

The prototype delivered impressive accuracy metrics:

- **99% accuracy** in pill detection and counting
- **Real-time processing** with sub-second response times
- **Reduced shrinkage loss** through automated inventory tracking
- **Time savings** for pharmacists on routine counting tasks

## Challenges

- **Training Data Quality**: Collecting diverse pill images for model training
- **Lighting Variability**: Ensuring accuracy across different lighting conditions
- **Pill Similarity**: Differentiating between visually similar medications
- **Real-World Validation**: Testing in actual pharmacy environments
